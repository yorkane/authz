## 部署/更新流程

```
bash
# 1. 构建（本机，authz 仓库根目录）
docker buildx build --load --build-arg JOBS=8 -t authz:latest .

# 2. 镜像同步：/nas2 中转（禁用 scp）
sudo bash -c 'docker save authz:latest | pigz -p 16 > /nas2/docker/authz-test.tar.gz'
ssh 241.t 'sudo bash -c "gunzip -c /nas2/docker/authz-test.tar.gz | docker load"'

# 3. 代码同步（改 Lua/前端/conf 无需重建镜像，同步+重建容器即可）
rsync -a admin lualib conf scripts test docker-entrypoint.sh 241.t:/data/app/authz-test/
# 注意：绝不 rsync 仓库根的 docker-compose.yml —— 241 用的是 241t 测试模板的副本
# （container_name: authz-test）。覆盖后 compose 会去抢 openresty-gateway 的名字并起错实例。
# 若误覆盖：cp docker-compose-241t-test.yml 过去改名恢复。

# 4. 重建并验证
ssh 241.t 'cd /data/app/authz-test && sudo docker compose up -d --force-recreate'
ssh 241.t 'curl -sk -o /dev/null -w "%{http_code}\n" https://127.0.0.1:6443/_authz/login'   # 期望 200
```

## 运维

```
bash
ssh 241.t 'sudo docker logs --tail 50 authz-test; sudo docker ps --filter name=authz-test'

# Agent API（仅 241.t 本机回环可用）
ssh 241.t "KEY=\$(sudo grep AUTHZ_AGENT_API_KEY /data/app/authz-test/.env | cut -d= -f2); curl -sk -H \"x-authz-key: \$KEY\" https://127.0.0.1:6443/_authz/api/session"

# 重置 admin 密码
ssh 241.t 'sudo docker exec authz-test admin_password_reset <new-password>'
```

.env 变更后必须 `docker compose up -d --force-recreate`（restart 不会重新读取 env）。
