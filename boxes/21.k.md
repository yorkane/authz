## 容器运维

```bash
# 状态
ssh 21.k 'docker ps -a --filter name=openresty-gateway-21k'

# 启停
ssh 21.k 'cd /data/app/authz-gateway && docker compose {up -d|down|restart}'

# 日志
ssh 21.k 'docker logs -f openresty-gateway-21k'

# 重置 admin 密码
ssh 21.k 'docker exec openresty-gateway-21k admin_password_reset <new-password>'

# 配置变更后重建
ssh 21.k 'cd /data/app/authz-gateway && docker compose up -d --force-recreate'
```
